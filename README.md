# Safra-BOT
Códigos de um BOT de economia que simula o Banco Safra, para cidades de roleplay que desejam um BOT completo de economia, possuindo comandos de saldo, investimentos, risco, transferência, entre outros comandos de administração e financeiros;
Est BOT é um dos BOTs mais completos em quesito financeiro que poderá encontrar, com grandes funcionalidades para aqueles servidores que desejam ter um foco financeiro, melhorar este setor, com opções de investimento, criação de conta automática ( O Bot cria Posts em canal de blog automáticamente, apenas a partir da seleção do canal do blog que deseja que os posts sejam criados ), funcionalidades de automação de alto nível, extremamente recomendado aquelas cidades que desejam ter um bot de economia. Focado em roleplaying.
